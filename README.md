# 전기기능사 학습실 ⚡

전기기능사 자격증 취득(필기/실기)을 위한 핵심 요약, 이론 정리, 그리고 기호 암기 도구들을 관리하는 나만의 학습 공간입니다.

## 📅 학습 과목 개요

전기기능사 필기는 크게 3가지 과목으로 구성되어 있으며, 각 과목의 기초는 **전기 기호와 단위를 완벽히 숙지하는 것**에서 시작합니다.

1. **전기이론**: 정전기, 자기, 교류 회로 등 기초 물리 및 회로 해석 (수학적 개념 다수)
2. **전기기기**: 발전기, 전동기, 변압기, 정류기 등의 원리와 특성 (기기별 구조 및 기호 필수)
3. **전기설비**: 전선, 배선 기구, 접지, 배선 공사 등 실무 규정 (KEC 한국전기설비규정 기반, 기호 암기 필수)

### `summaries.html` 은 손으로 고치지 않는다

마크다운 3개(`Theory_Summary.md` · `Machinery_Summary.md` · `Facility_Summary.md`)가
원본이고, HTML 은 **스크립트가 만든다.** `Theory_Extra_전기기사대비.md` 처럼 그 3개에
안 든 문서는 요약집에 반영되지 않는다 — 기능사 범위 밖 참고 자료라 일부러 뺐다.
셋 중 하나를 고쳤으면 다시 돌린다:

```bash
python build_summaries.py
```

> **⚠ 돌린 뒤 마지막 줄을 볼 것 — "모르는 수식 명령" 경고가 뜨면 그냥 넘어가지 말 것.**
> 이 스크립트는 TeX 를 직접 HTML 로 바꾸는데(외부 라이브러리 없음), 모르는 명령은
> **화면에서 통째로 사라진다.** 실제로 `\sigma` 를 몰라서 $E = \sigma/2\varepsilon_0$ 가
> `E = 2ε₀` 로 나온 적이 있다 — **틀린 공식보다 나쁘다. 보는 사람이 이상한 줄도 모른다.**
> 경고에 뜬 기호는 `build_summaries.py` 의 `SYMBOLS` 에 추가하고 다시 돌린다.
> (2026-09-04 에 `\sigma` `\oint` `\Leftrightarrow` `\cdots` 를 이렇게 찾아 고쳤다.
> `\Leftrightarrow` 는 8군데에서 안 보이고 있었다.)

> **⚠ 굵게(`**`)는 한 줄 안에서 닫을 것.**
> 인용문(`>`)과 목록은 **줄마다 따로** 처리하기 때문에, 굵게가 줄을 넘으면 닫히지 않고
> 화면에 별표가 그대로 보인다. 이것도 빌드가 잡아서 알려준다.

### 수식은 한 줄에 하나씩 쓴다

`$$ ... \qquad ... $$` 처럼 한 줄에 공식을 두세 개 욱여넣으면 폰에서 읽기 어렵다.
**조건을 위에 붙이고 공식을 따로 놓는다** — 교재와 같은 모양이 된다.

```markdown
**바깥** — $r \ge R$
$$E = \frac{Q}{4\pi\varepsilon_0 r^2}$$

**안** — $r < R$
$$E = 0$$
```

   - 전기설비 과목은 전선 색상(갈, 흑, 회, 청 - 보호도체 녹-황 혼합) 등 한국전기설비규정(KEC) 최신 개정본을 기준으로 암기해야 합니다.

   - 옴의 법칙($I = V/R$), 전력($P = VI$) 등 핵심 공식은 눈으로만 보지 말고 연습장에 직접 회로도를 그리며 대입해 봅니다.
